# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic word-guessing game in Python. Practice string manipulation, loops, conditionals, user input, and random selection while creating an interactive game.

## 📝 Tasks

### 🛠️ Set Up the Hidden Word

#### Description
Create the game setup by selecting a hidden word and displaying the player's progress as they guess its letters.

#### Requirements
Completed program should:

- Randomly select a hidden word from a predefined list.
- Ask the player to enter one letter at a time.
- Display guessed letters in their correct positions and use underscores for letters that have not been guessed, such as `_ _ a _`.

### 🛠️ Manage the Game

#### Description
Add the game loop and rules needed to track guesses, determine the outcome, and tell the player whether they won or lost.

#### Requirements
Completed program should:

- Track and display the number of incorrect guesses remaining.
- Continue accepting guesses until the hidden word is complete or the player runs out of attempts.
- Display a winning message when the player guesses the word.
- Reveal the hidden word and display a losing message when the player runs out of attempts.
