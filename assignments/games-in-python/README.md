# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic word-guessing game to practice Python strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Choose and Display a Hidden Word

#### Description
Create the starting state for a Hangman game by choosing a word at random and showing the player which letters have been guessed.

#### Requirements
Completed program should:

- Choose a word at random from a predefined list.
- Keep track of the letters guessed so far.
- Display each unguessed letter as an underscore, such as `_ _ _ _`.

### 🛠️ Play the Guessing Game

#### Description
Let the player guess letters until they reveal the word or run out of incorrect guesses.

#### Requirements
Completed program should:

- Ask the player to guess a letter and update the displayed word when the guess is correct.
- Track and display the number of incorrect guesses remaining.
- End when the player guesses the word or runs out of incorrect guesses.
- Display a clear win or lose message and reveal the word at the end of the game.
